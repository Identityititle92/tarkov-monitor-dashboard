## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Raid Charts** | Visual charts of KD, survival rate and profit trends over time |
| **Session Summary** | Per-session summaries with total loot value and key statistics |
| **Trader Timers** | Countdown timers for all Tarkov trader restock schedules |
| **Goal Tracker** | Set personal raid goals and track progress toward them |
